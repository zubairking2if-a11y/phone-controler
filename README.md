# Phone Controller

A Flask-based application for controlling and managing phone operations remotely.

## Features

- Remote phone control via HTTP API
- CORS-enabled for cross-origin requests
- Lightweight and easy to set up

## Requirements

- Python 3.x
- Flask
- Flask-CORS
- requests

## Installation

1. Create a virtual environment:
```bash
python3 -m venv venv
```

2. Activate the virtual environment:
```bash
source venv/bin/activate
```

3. Install dependencies:
```bash
pip install Flask Flask-CORS requests
```

## Usage

Run the application:
```bash
python3 phone_control_system.py
```

The application will start and be ready to accept requests.
